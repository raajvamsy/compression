The idea

Feed the output back in, count the loops

Start at 1, run it through the equation, feed the answer back in, again and again. When the output spells your file, stop. Save only the loop count.

Result 1

It works: every equation prints the file back exactly

8 ways to turn a file into an equation. Each was tested on text, code, data, photos, sound and video. The 7 lossless ones matched the original bit for bit; the wave equation (made for pictures and sound) rebuilds a close copy.

Result 2 · why it can't shrink

There are more files than short names

Take every possible 4-bit file: there are 16. Try to give each one a shorter, 3-bit "equation". There are only 8 of those. Whatever equation, loop or tree you use, half the files have no short name left.

16 possible files (4 bits)

→

only 8 shorter names (3 bits)

Even counting every shorter name (0, 1, 2 or 3 bits: 15 in total) there are still fewer than 16. That's the pigeonhole principle. It holds for any lossless scheme, so on average the stored equation is at least as big as the file.
What the loop actually cost

The loop count is as long as the file

To print "hi" (16 bits) the loop ran 111,621 times. Writing down 111,621 takes 17 bits, one more than the file. Every extra bit of file doubles the number of loops.

Not to scale: every single extra bit doubles the work. Times for 2–3 chars were measured on this Mac. The 8-char time is extrapolated from the fastest (vectorised) search, at about 70 million tries per second.

The FunnelBrain tree

The funnel never narrows, it widens

The hope: split the file into pieces, give each piece a sub-equation, then make a master equation of the sub-equations, until one small equation is left. In reality each sub-equation costs more bits than the piece it prints, so every level gets bigger.

A photo as a sum of waves

Same file size, four pictures

The photo rebuilt from 8,938 cosine waves in 16×16 tiles (one sub-equation per tile), next to JPEG and WebP squeezed into the same ~6.7 KB. Hover to zoom. Higher dB = closer to the original.

Across 4 images the wave equation lands about level with JPEG (it is JPEG's own idea) and 2–4 dB behind WebP. One finding backs the FunnelBrain instinct: many small sub-equations beat one big equation on every image.
