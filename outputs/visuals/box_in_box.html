Raaj's idea · box in box

Boxes inside boxes

Split the picture into n×n boxes, each box into n×n again, and so on. Then compress the boxes instead of the whole image. Does it help? We tried four versions on four raw images. Every result is lossless.

The four versions

Same idea, four ways to use it

Fixed boxes

Every box gets its own fresh model. All boxes run at the same time on different cores.

Warm boxes

Same boxes, but each model first reads the box above and the box to its left. It stores nothing for them, because the decoder already has them.

Adaptive quadtree

Split a box into 4 only if the 4 pieces together come out smaller than the box.

Box-in-box order

One model for the whole image, visiting pixels box inside box (Z-order) instead of row by row.

Verdict

Does it improve?

✓ A little, if shallow

2×2 boxes, one or two levels deep, with warm starts: 0.4–0.9% smaller on the two big photos (landscape, wallpaper). Each part of a photo (sky, sea, rocks) gets a model tuned to it.

✓ Much faster

Boxes are independent, so they run on all cores. Fixed 2×2 boxes ran about 3× faster than the whole image (landscape 1.25 s → 0.37 s). It's the same trick that made the 4K JPEG fast.

✗ Deep nesting hurts

Every new box starts knowing nothing, so small boxes spend their bytes re-learning. At 3×3 boxes three levels deep (729 boxes), the landscape grows 57%, or 19% even with warm starts. Flat pictures suffer most: the synthetic image grows 30% to 9× with fixed boxes.

✗ Box-in-box order is worse

Visiting pixels box by box breaks "the pixel above is one row back". The grid lens loses its neighbour, and files grow 15% to 22×.

◐ Adaptive picks almost nothing

The quadtree decided to split only once (4 boxes) on the big photos, and never on the small ones. Even when it searches freely, big boxes win.

→ What to keep

Box-in-box as a speed tool: 2×2 or 4×4 warm boxes for big images (parallel, slightly smaller), chosen by Listen like the other settings. Not as a way to compress much smaller. The model already adapts inside one big box.
