EquaFile · follow-up #2

A file as waves,
found by resonance

Treat the file as a signal. Let a bank of oscillators listen to it: the ones that ring are the file's natural frequencies. Add those waves together (superposition) and store only what they can't explain.

Step 1 · Resonance

Drive 351 tuning forks with the file and see which ones ring

Each fork is a real driven, damped oscillator (200–900 Hz). It is fed the first 4,096 samples of the 3-note chord. Only forks matching a hidden frequency build up energy, just like a swing pushed at the right rhythm.

Does every file resonate?

Only files that really are waves

Share of all ringing energy held by the strongest 30 resonators out of 8,192 (each pure tone also makes about 10 neighbouring forks ring). A file made of waves concentrates its energy; text and random bytes spread it everywhere.

Step 2 · Superposition

Add the ringing waves together → the file comes back

The three waves the resonators found, added sample by sample, overlaid on the real file. What's left over is ±1 rounding noise, stored exactly so the file comes back bit for bit.

Step 3 · But for ordinary data?

"hi" as waves: how many waves until every bit is right?

The 16 bits of "hi" as a signal. Add its waves from strongest to weakest and read each point as 0 or 1.
