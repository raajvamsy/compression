EquaFile — POC results

Every file stored as an equation, decoded back and checked. Below: does the loop idea shrink files, does the FunnelBrain tree narrow, and how do equation families compare with gzip/xz/brotli, PNG/JPEG/WebP, MP3/Opus and H.264?

1 · The loop and the seed search

Each dot is one random target. The dashed line is break-even: below it the equation would be smaller than the file. Individual lucky targets dip below it, but once the decoder is told how long the stored number is (the "length prefix" table in REPORT_DATA.md), every bit size averages above it. Search time doubles with every extra bit.

2 · The FunnelBrain tree never narrows

Each level replaces 16-bit chunks with the seeds of sub-equations that print them. A seed costs about 18.5 bits per 16-bit chunk, so every level grows by ~16% instead of shrinking toward one master equation.
